# V6 project scope and cost gate

## Approved budget ceiling carried forward

| Cost center | Budget | Scope |
|---|---:|---|
| UI/UX + creative direction | $5,000 | Art direction, motion storyboard, Figma designs, responsive states, QA handoff |
| Development | $10,000 | Next.js/React, CMS, contact API, SEO, WebGL experience, optimization, QA and deployment work |
| **Total** | **$15,000** | Excludes new project photography, BIM authoring, model capture/scanning, hosting or paid services |

The cinematic upgrade is designed to remain **within the previously planned single-model 3D workstream** (~$1,400 design direction + ~$2,600 development as an envelope). This is a planning assumption and a scope trade: it does **not** include 3D digital twins for the six named projects, high-end environmental rendering, exterior animations for multiple building types, or bespoke GLB asset production.

The 3D playback additions mean the technical team's hour allocation must be reconciled against the existing $10k dev backlog. If creating a production-ready high-fidelity model plus guaranteed 60 FPS on every device is required, re-estimation is mandatory; do not silently treat those obligations as free.

## Delivery gates

- **Design gate:** five illustrated motion scene storyboards and user controls signed off (VI/EN, desktop/mobile/reduced-motion).
- **Development gate:** motion implemented in React and Next.js, real device tests, camera interpolation, autoplay visibility management and keyboard/manual support.
- **Content gate:** all statements about real work and ownership approved, with actual project images and details licensed.
- **Release gate:** production build, staging QA, API, CMS, SEO redirects, WebGL fallback and operations owners assigned.
